# \## 📌 About the Project

# 

# \*\*AI Resume Analyser\*\* is a full-stack, AI-assisted resume intelligence and document-generation platform designed to help students, job seekers, and professionals evaluate, refine, and professionally present their resumes.

# 

# The application combines local Natural Language Processing (NLP), structured resume evaluation, job-description matching, and optional Generative AI capabilities to provide practical career-development assistance.

# 

# Its \*\*local-first architecture\*\* allows users to analyze resumes, identify skills, evaluate job compatibility, and generate professional documents without relying on paid AI APIs.

# 

# For enhanced contextual rewriting, users can optionally integrate Google's Gemini AI.

# 

# The platform goes beyond basic resume analysis by offering an integrated \*\*Resume Studio\*\*, enabling users to edit resume content, apply professional templates, and export customized documents in PDF or DOCX format.

# 

# \---

# 

# \## ✨ Key Features

# 

# \### 📄 1. Intelligent Resume Processing

# 

# Upload resumes in multiple formats and automatically extract their textual information.

# 

# \*\*Supported formats:\*\*

# \- PDF

# \- DOCX

# \- TXT

# \- Direct text input

# 

# The system processes extracted content and prepares it for analysis, evaluation, and resume optimization.

# 

# \### 🧠 2. NLP-Based Resume Analysis

# 

# Analyze resume content using local text-processing techniques and predefined skill dictionaries.

# 

# The analysis includes:

# 

# \- Technical skill identification

# \- Resume content evaluation

# \- Section-wise assessment

# \- Skill coverage analysis

# \- Resume strengths and weaknesses

# \- Improvement recommendations

# 

# Results are presented through a structured interface designed to help users understand how their resumes can be improved.

# 

# \### 🎯 3. Job Description Matching

# 

# Compare a resume against a specific job description to assess its relevance to the target position.

# 

# \*\*Capabilities include:\*\*

# 

# \- Job-related keyword matching

# \- Skill requirement comparison

# \- Missing skill identification

# \- Compatibility assessment

# \- Recommendations for resume improvement

# 

# This feature helps users customize their resumes for specific job opportunities.

# 

# \### 📊 4. Resume Scoring \& Performance Insights

# 

# The application generates an explainable resume assessment based on heuristic scoring methods.

# 

# \*\*Analysis includes:\*\*

# 

# \- Overall resume score

# \- Category-wise evaluation

# \- Skill matching

# \- Missing qualifications

# \- Actionable recommendations

# 

# Scores are intended as informational estimates and are not official Applicant Tracking System (ATS) scores.

# 

# \### 🤖 5. AI-Powered Resume Optimization

# 

# Improve resume quality through intelligent rewriting and content refinement.

# 

# The platform supports two optimization methods.

# 

# \*\*Local Resume Optimization\*\*

# 

# Provides conservative wording and formatting improvements without requiring an external AI service.

# 

# \*\*Gemini AI Integration\*\*

# 

# Optionally enables contextual rewriting using Google's Gemini API.

# 

# AI-assisted optimization can improve:

# 

# \- Professional summaries

# \- Project descriptions

# \- Work experience descriptions

# \- Resume wording

# \- Clarity and professional tone

# 

# Users can review changes section by section and restore original content when required.

# 

# AI-generated suggestions should always be reviewed to ensure factual accuracy.

# 

# \### 🎨 6. Professional Resume Studio

# 

# An integrated resume-building workspace that allows users to create and customize professional documents.

# 

# \*\*Features include:\*\*

# 

# \- Direct resume upload

# \- Automatic extraction into editable fields

# \- Resume content editing

# \- Section-wise customization

# \- Document previews

# \- Browser-saved drafts

# \- Template selection

# \- Export to professional document formats

# 

# Resume Studio allows users to move from resume analysis to document creation within the same application.

# 

# \### 📝 7. Customizable DOCX Templates

# 

# Generate fully editable Microsoft Word resumes using built-in templates or compatible custom DOCX designs.

# 

# The application includes \*\*three built-in Word export templates\*\*.

# 

# Users can also upload templates containing supported placeholders.

# 

# ```text

# {{NAME}}

# {{CONTACT}}

# {{SUMMARY}}

# {{SKILLS}}

# {{EXPERIENCE}}

# {{PROJECTS}}

# {{EDUCATION}}

# {{CERTIFICATIONS}}

# ```

# 

# The backend replaces these placeholders with the corresponding resume information during document generation.

# 

# \### 📑 8. PDF Template Customization

# 

# Upload custom PDF designs and map resume information onto the document.

# 

# \*\*PDF Template Mapping Workflow:\*\*

# 

# 1\. Upload a PDF template.

# 2\. Preview the template.

# 3\. Select the resume field to insert.

# 4\. Position the field using the visual preview.

# 5\. Customize field dimensions and font size.

# 6\. Configure the target page and placement.

# 7\. Export the completed PDF.

# 

# The application preserves the template's original artwork while overlaying candidate information.

# 

# \*\*Supported PDF template limits:\*\*

# \- Maximum file size: 8 MB

# \- Maximum pages: 8

# 

# \*\*Note:\*\* PDF templates use fixed-position text overlays. They do not support automatic reflow of existing document content.

# 

# \### 🌓 9. Modern \& Responsive User Interface

# 

# The application includes a polished, responsive frontend designed for comfortable resume analysis and editing.

# 

# \*\*Interface features:\*\*

# 

# \- Modern dashboard

# \- Responsive layouts

# \- Light and dark themes

# \- Smooth page transitions

# \- Framer Motion animations

# \- Reduced-motion accessibility support

# \- Persistent browser preferences

# \- Adjustable application zoom

# \- Independent document preview zoom

# 

# \*\*Application zoom:\*\* 90%–150%

# 

# \*\*Document preview zoom:\*\* 75%–200%

# 

# \### 💾 10. Local Data Persistence

# 

# SQLite provides lightweight local storage for resume-analysis history.

# 

# The application also supports browser-based draft persistence, helping users continue editing their resumes without repeatedly entering information.

# \## ⚙️ Installation \& Setup

# 

# \### Prerequisites

# 

# Ensure the following are installed:

# 

# \- Python 3.11 or later

# \- Node.js 20 or later

# \- npm

# \- Git

# 

# \### Step 1 — Clone the Repository

# 

# ```bash

# git clone https://github.com/YOUR\_USERNAME/AI-Resume-Analyser.git

# 

# cd AI-Resume-Analyser

# ```

# 

# Replace `YOUR\_USERNAME` with your GitHub username.

# 

# \### Step 2 — Backend Setup

# 

# Open a terminal in the project directory.

# 

# ```powershell

# cd backend

# ```

# 

# Create a virtual environment:

# 

# ```powershell

# py -3.11 -m venv .venv

# ```

# 

# Activate the environment:

# 

# ```powershell

# .\\.venv\\Scripts\\Activate.ps1

# ```

# 

# Install Python dependencies:

# 

# ```powershell

# python -m pip install -r requirements.txt

# ```

# 

# Start the FastAPI backend:

# 

# ```powershell

# python start.py

# ```

# 

# The backend will be available at:

# 

# `http://127.0.0.1:8000`

# 

# \### Step 3 — Frontend Setup

# 

# Open a second terminal in the project root.

# 

# ```powershell

# cd frontend

# ```

# 

# Install dependencies:

# 

# ```powershell

# npm install

# ```

# 

# Start the React development server:

# 

# ```powershell

# npm run dev

# ```

# 

# Access the application at:

# 

# \*\*http://127.0.0.1:5173\*\*

# \## ⚠️ Technical Limitations

# 

# The following limitations are important when interpreting results and using the application:

# 

# \*\*Resume Scoring:\*\* Uses heuristic evaluation rather than an employer's actual ATS algorithm.

# 

# \*\*Skill Extraction:\*\* Uses local dictionaries and text-processing techniques that may not recognize every synonym or skill expression.

# 

# \*\*Machine Learning:\*\* The current implementation does not include a trained ML-based job-role classifier.

# 

# \*\*AI Rewriting:\*\* Gemini-generated suggestions require human verification.

# 

# \*\*Document Extraction:\*\* Scanned or image-only PDFs require OCR, which is not currently implemented.

# 

# \*\*PDF Templates:\*\* Existing text is not automatically removed or reflowed.

# 

# \*\*Cloud Deployment:\*\* Additional security and infrastructure are needed for production multi-user use.
